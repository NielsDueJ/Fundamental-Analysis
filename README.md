# Fundamental-Analysis

Fundamental analysis of a single stock: key ratios (P/E, operating and free cash flow, EBITDA), price charts with moving average and Bollinger Bands, a candlestick chart, recent news, and a comparison with industry peers.

Data comes from Yahoo Finance, Financial Modeling Prep and NewsAPI. The last two need API keys, which you set in the notebook before calling `perform_analysis(ticker, fmp_api_key, news_api_key)`.
